# Backend

- `config/` – Datenbank
- `middleware/` – Authentifizierung
- `services/` – Datenzugriff und Anwendungsfunktionen
- `controllers/` – Request-/Formularlogik
- `routes/` – URL-Übersicht

Die Controller werden von den bestehenden Frontend-Views aufgerufen. Dadurch bleibt die Funktionalität unverändert.
